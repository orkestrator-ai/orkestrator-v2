00005 · Put white text only on primary-fill

To do High Color tokens Evidence 0 / 8 images

Problem

bg-primary text-primary-foreground puts white on #3b82f6 (3.7:1). The shared checkbox does it when checked, so every checkbox in the app is affected. So do the chosen-option indicators on question cards, the completed-step number badge in the auto pipeline tab and the hover “add comment” button in the PR diff.

The Fill Rule. White text sits only on primary-fill, never on primary. primary is for lines, text and marks on the dark ground.
DESIGN.md, Colors → Named Rules; white on primary is 3.7:1, below AA

Find every instance

grep -rnE --include=*.tsx 'bg-primary( |"|$)' apps/web/src | grep -v '\.test\.' | grep -E 'text-(white|primary-foreground)'

Approach

  1. Swap bg-primary for bg-primary-fill wherever white text or a white glyph sits on it; keep border-primary.
  2. For the checkbox, keep the focus hairline outset on the filled state (already present).
  3. Replace the emerald-700 button with <Button> so it takes the primary fill, focus hairline and hover behavior.
  4. Check the text selection color is still readable in inputs.
