# Coordinator report C1 (Wake reliability): outcome

The item-by-item check of batch C1 against its report, which was deleted once
the check was complete. The report was file `0010` in `docs/reports/coordinator/`.
It can still be read at base commit `48d2ed40c`:
`git ls-tree 48d2ed40c docs/reports/coordinator/` lists it as the C1 file.

The report's seven numbered tasks are done, with tests. No finding had stopped
holding: on re-check against current code all six parts still applied, with only
their line numbers moved. So no row below says "no longer holds". Two things need
live evidence that could not be gathered here, and both moved to to-do
[4860](../todo/coordinator-and-multi-review/4860-c1-wake-reliability-follow-ups.md).

All the tests below use fakes and in-process stores. No real store was read and
no two-node run took place, which is why those two items are in the to-do.
